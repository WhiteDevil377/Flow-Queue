# Flow Queue

Flow Queue is a Manifest V3 Chrome extension for fast, organized Google Flow batch automation.

It is a fresh React + Vite + TypeScript rewrite. It does not include the packed source extension's minified bundles, branding, logo, paid feature gates, remote authorization checks, or bundled unlicensed fonts.

## Build

```bash
npm install
npm run build
```

Load the `dist` directory as an unpacked Chrome extension.

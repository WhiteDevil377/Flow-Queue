# Flow Queue Privacy Policy

Effective date: June 20, 2026

Flow Queue is a Chrome extension that automates user-directed image and video prompt queues in Google Flow.

## Data Flow Queue handles

Flow Queue may process the following data locally in the user's browser:

- Prompts entered or imported by the user
- Reference images selected by the user
- Google Flow page content needed to locate controls and monitor generation status
- URLs and filenames of generated media selected for download
- Extension settings, language, appearance, run status, and diagnostic logs
- Cookies scoped to `flow.google.com` and `labs.google`, only when the user explicitly selects Clear cache

## How the data is used

The data is used only to:

- Submit user-selected prompts and reference images to Google Flow
- Monitor user-requested image and video generation
- Download and organize completed media when Auto download is enabled
- Save extension preferences locally
- Display local run status and diagnostics
- Clear the Google Flow session when the user explicitly requests it

## Storage

Settings and diagnostic logs are stored locally using Chrome extension storage. Flow Queue does not use Chrome Sync for this data. Prompts and reference images are held only as needed for the current browser session and queue workflow.

## Sharing and third parties

Flow Queue does not operate a developer server and does not transmit user data to Abhishek Kumar, advertising networks, analytics providers, data brokers, or other third parties.

When the user runs a queue, the selected prompts and reference images are submitted to Google Flow at the user's direction. Google processes that content under Google's own terms and privacy policy. Downloaded media is handled by Chrome's download system and saved to the user's device.

## Cookies and authentication information

Flow Queue does not use cookies for tracking. If the user clicks Clear cache, the extension accesses cookies scoped to `flow.google.com` and `labs.google` only to remove them and reset the Google Flow session. Cookie values are not stored, logged, or transmitted.

## Clipboard

Flow Queue may write user-selected content or diagnostic text to the clipboard as part of a user-facing action. It does not read clipboard contents.

## Data sales, advertising, and profiling

Flow Queue does not sell user data. It does not use user data for advertising, profiling, creditworthiness, lending, or unrelated purposes.

## Security

Flow Queue limits access to `flow.google.com` and `labs.google` and uses only extension-packaged executable code. Any communication with Google Flow occurs over HTTPS.

## Data deletion

Users can remove locally stored settings and logs by uninstalling the extension. Diagnostic logs can also be deleted using Clear logs inside the extension.

## Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes

This policy may be updated when the extension's behavior changes. The effective date above will be updated when material changes are published.

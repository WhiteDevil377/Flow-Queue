# Deploy These Public Pages

This folder is a complete static website. Upload every HTML file without renaming or changing capitalization.

After deployment, the URLs will be:

- Homepage: `https://YOUR-DOMAIN/`
- Support: `https://YOUR-DOMAIN/SUPPORT.html`
- Privacy policy: `https://YOUR-DOMAIN/PRIVACY_POLICY.html`

## GitHub Pages

1. Create a public GitHub repository such as `flow-queue-site`.
2. Upload the contents of this folder to the repository root.
3. Open repository Settings, then Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub to display the public HTTPS address.
7. Open all three URLs above and verify that they work without signing in.

Use the public privacy-policy URL in the Chrome Web Store Privacy practices tab. Use the homepage and support URLs in the Store listing tab.

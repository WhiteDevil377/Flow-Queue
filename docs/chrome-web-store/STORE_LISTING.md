## Detailed description

Flow Queue helps creators run organized batches of image and video prompts in Google Flow™ from a focused Chrome side panel.

Add prompts manually or import a text, CSV, TSV, or JSON file. Choose an image or video workflow, select model and output settings, control concurrency and retry behavior, and monitor each run from one place.

Key features:

- Queue multiple prompts for image or video generation
- Text-to-video, image-to-video, text-to-image, and image-to-image modes
- Configurable concurrency, delays, retries, aspect ratios, duration, and output count
- Optional reference-image assignment for individual prompts
- Automatic image and video downloads
- Download folder, filename prefix, and automatic numbering controls
- Run progress, per-prompt status, and local diagnostics
- Multiple interface languages
- Local settings and logs with no developer-operated analytics service

Flow Queue works only on `flow.google.com` and `labs.google` pages used by Google Flow. Prompts, uploaded reference images, generated-media details, settings, and diagnostic logs are processed locally by the extension. When you run a queue, the content you selected is submitted to Google Flow at your direction and is subject to Google's terms and privacy practices.
